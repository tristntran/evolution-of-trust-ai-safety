A prompt archetype is an AI player: a model plus a prompt describing who it is. Each round it sees the rules and the history so far, then picks Cooperate or Cheat. Put prompts up against the original characters, or against each other.

Connect your own account

This app has no API keys and no server. AI moves are paid for by your account, and your credentials stay in this browser. They're only ever sent to the provider you connect.

Mock

Always available, free, offline. Runs a built-in strategy through the whole prompt pipeline, so you can test the setup before spending anything.

Why not "Sign in with Claude"? Anthropic doesn't let third-party apps use Claude.ai logins, so Claude models are reached through OpenRouter (or Puter), which bills your own account. OpenAI's "Sign in with ChatGPT" plan usage currently covers only open-source tools that run locally, and could be added as a provider later.

Default models

Used by any prompt archetype that doesn't name its own model.

The Decisions API is the default engine: the model picks Cooperate or Cheat from a fixed list and returns its probabilities. It's fast, and output tokens are free, so it suits thousands of moves.

Response cache

With temperature 0, the same situation gets the same answer, so answers are cached in this browser. That cuts evolution runs from thousands of calls to a few hundred.
